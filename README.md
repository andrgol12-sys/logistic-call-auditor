# ЛогистПро — Аудит звонков

Telegram-бот принимает аудио или видео, получает транскрипт с разделением говорящих через AssemblyAI, оценивает звонок менеджера транспортно-логистической компании через OpenAI и сохраняет результат в PostgreSQL.

## Возможности

- Оценка первичного звонка по 11 критериям из `prompt.md`.
- Транскрипт и аудит в Telegram.
- Итоговые баллы вычисляются кодом по статусам критериев.
- Локальный запуск в Docker без VPS.
- 11 офлайн-тестов и отдельная интеграционная проверка PostgreSQL.

## Запуск

1. Установите Docker Desktop с Docker Compose.
2. Создайте `.env` из `.env.example` и локально заполните `TELEGRAM_BOT_TOKEN`, `ASSEMBLYAI_API_KEY`, `OPENAI_API_KEY`. При необходимости измените `OPENAI_MODEL`.
3. Выполните:

```sh
docker compose up -d --build
```

В Compose адрес базы задаётся автоматически; PostgreSQL доступен только внутри Docker-сети. В Telegram отправьте `/start`, затем короткий MP3 как аудиофайл или документ. Голосовые сообщения пока не поддерживаются. Реальная обработка использует внешние API и может расходовать баланс.

Остановка:

```sh
docker compose down
```

## Проверки без ключей

Только Python 3.12 и стандартная библиотека:

```sh
python test_offline.py
```

Проверка реального импорта зависимостей, создания схемы PostgreSQL и записи/чтения синтетических данных:

```sh
docker compose build bot
docker compose -p pecb10-offline-check -f docker-compose.offline.yml up --abort-on-container-exit --exit-code-from check
docker compose -p pecb10-offline-check -f docker-compose.offline.yml down
```

Сборка загружает зависимости. Во время интеграционной проверки контейнеры используют внутреннюю сеть без выхода в интернет, база временная; Telegram, AssemblyAI и OpenAI не вызываются.

## Структура

- `bot.py` — обработка медиа, распознавание, аудит и сохранение.
- `prompt.md` — роль, критерии и правила оценки.
- `test_offline.py` — тесты с синтетическими данными и заменой сетевых клиентов.
- `container_check.py` — локальная интеграционная проверка PostgreSQL.
- `docker-compose.yml` — рабочий локальный запуск.
- `docker-compose.offline.yml` — изолированная проверка без ключей.

## Результат и ограничения

В тесте 9 ноября 2026 года MP3 успешно прошёл Telegram → AssemblyAI → OpenAI. После исправлений итог 22/22 согласован со всеми 11 статусами; 11 офлайн-тестов прошли. Это проверка одного синтетического звонка, а не качества системы на реальных разговорах.

Модель может неточно цитировать и определять говорящего; качество транскрибации также не гарантировано. Баллы проверяются кодом, содержание выводов требует проверки человеком. Проект учебный: нет полной обработки всех лимитов файлов, проверки цитат или производственной защиты данных; в Compose используются учебные реквизиты БД.

`.env`, записи звонков, журналы и данные базы не входят в репозиторий. Не публикуйте ключи и реальные разговоры. Журналы приложения ограничены фиксированными сообщениями и категориями ошибок.
